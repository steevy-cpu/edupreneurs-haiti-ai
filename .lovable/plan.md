
# Auto-Publish Lessons After Batch Content Generation

## What Changes
After each lesson's content is successfully generated by the "Contenu manquant uniquement" batch operation, the lesson will be automatically published (set `is_published = true` and `workflow_status = 'approved'`).

## How It Works
The content generator already has an `updateLesson` callback that currently does nothing (the edge function saves the content). We will use this callback to also set the lesson as published when generation succeeds.

## Technical Details

### File: `src/features/content-editor/batch-operations/generators/contentGenerator.ts`

Update the `updateLesson` function (currently a no-op at line 152) to publish the lesson after successful generation:

```typescript
updateLesson: async (lessonId: string, result: any) => {
  // The process-ai-job edge function already saves the content
  // Now also auto-publish the lesson
  if (result.success) {
    const { error } = await supabase
      .from('lessons')
      .update({ 
        is_published: true, 
        workflow_status: 'approved' 
      })
      .eq('id', lessonId);

    if (error) {
      console.error('Auto-publish failed for', lessonId, error);
    }
  }
},
```

Also update the dialog description and success message to inform admins that lessons will be auto-published:

- **Description**: Add mention that lessons will be published automatically
- **Success message**: Update to mention publication
