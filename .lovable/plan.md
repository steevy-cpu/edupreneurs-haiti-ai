## Features

- AI-powered lesson and quiz generation
- Interactive activities aligned with curriculum
- Multi-language support (French / Haitian Creole)
- Progressive Web App with offline capabilities
- Push notifications
- Content validation workflow

## Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS
- **UI Components**: shadcn/ui, Framer Motion
- **Backend**: Lovable Cloud, Edge Functions (Deno)
- **Data**: TanStack Query, Real-time subscriptions

## Development

### Prerequisites
- Node.js & npm ([install with nvm](https://github.com/nvm-sh/nvm))

### Setup
git clone <repository-url>
cd edupreneurs
npm install
npm run dev

- This is a private repository
- All API keys and secrets are stored as environment variables
- No sensitive data is committed to the codebase
